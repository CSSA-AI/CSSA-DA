# CSSA 问答助手 —— 网页设计需求

给设计团队看。

要做的东西很简单:**一个问答页面**。用户打字问问题,它回一段话,下面放几篇参考文章。

第一版只给社团内部和几十个志愿者用,不对外,**只做电脑版**。做得能用、好看、有
CSSA 的味道就行,不用抠细节。

---

## 一、要画这几个画面

1. **刚打开的页面** —— 写一句「我能答什么、答不了什么」就行。**别放示例问题**,
   这一版就是想看看大家自己会问什么,给了例子大家照着点,就收不到真东西了
2. **等回答的时候** —— 这个要多花点心思,原因见第二节
3. **回答出来了** —— 一段回答 + 几篇参考文章 + 👍👎 两个按钮
4. **参考文章的卡片** —— 一般 3 篇
5. **出错了** —— 画一个就行,不同情况只是换句话
6. **问题打太长** —— 超过 4000 字就不让发

出错有这几种情况,画面长一样,只换文字:

| 什么情况 | 跟用户说什么 |
|---|---|
| 问得太快(一分钟最多 10 次) | 等一分钟再问 |
| 服务器坏了 / 不知道哪出错了 | 待会儿再试,给个「重试」按钮 |
| 等太久了(超过 30 秒) | 换个说法或者待会儿再试,给个「重试」按钮 |
| 登录过期了 | 去重新登录 |
| 网络断了 | 检查一下网络 |

> 出错的时候,**用户刚打的字别给弄丢了**,这个最容易被骂。

---

## 二、有几件事得先知道

不说的话你们猜不到,猜错了就得重画:

| | |
|---|---|
| **参考文章没有标题** | 我们存的资料里就没有标题这个东西。所以卡片上写什么当标题,要你们想 —— 用「这篇能回答的问题」?还是把正文开头截一句?另外作者、来源有时候也是空的 |
| **回答要等很久,最长 30 秒** | 而且不像 ChatGPT 那样一个字一个字往外蹦,是等半天然后整段一起出来。所以等的时候别只放个转圈的图标,建议分几步给点提示,比如先写「正在找资料…」再变成「正在整理回答…」,让人知道它没死 |
| **它经常答不上来** | 资料不多,「这个我答不上来」会很常见。但这就是一句普通的回答,不用单独画一个画面 |
| **参考文章要写清楚发布日期,还要能点进原文** | 有些推文很老了,得让人自己判断是不是过时了 |
| **一次最多打 4000 字** | 超了就不让发 |

## 三、想要什么感觉

配色贴着社团的整体感觉走就行,让人看出来是 CSSA 的东西。不用照搬 logo 的颜色,
你们随便发挥。

**干净、简单、像个工具。** 别搞那种一看就是「AI 产品」的紫色渐变、发光、闪来闪去
的特效,也别加卡通吉祥物。多留白,东西摆清楚就行。感觉上更像学校官网里一个好用的
查询页面,不是什么未来科技。

**上面的字要说人话。** 比如写「你问得有点快,等一分钟」,别写「请求频率超出限制」;
写「正在找资料…」,别写「正在进行语义检索」。

**要有一行小字**,意思是「回答是 AI 写的,可能不准也可能过时,签证、学籍这种大事
请以官方为准」。这行必须有,放哪、怎么写你们定。

⚠️ 别写「留学百事通」「什么都能问」这种话。第一版资料很少,基本只能答墨大课程的事,
和社团推文里写过的事。用户抱着太高期望进来,只会失望。

## 四、这一版不做

手机版 · 暗色模式 · 英文版 · 一个字一个字往外蹦的效果 · 历史聊天记录(每次打开都是
全新的)· 语音输入 · 传图片 · 分享导出 · App 和小程序
